# huffman-dotnet

A Huffman coding library and (planned) web API written in C#/.NET.

## About

This project is a redesign of my old [C++ CLI project](https://github.com/blake125/huffman-project). Since I'm taking a distributed development class using C#/.NET, I figured this would be a good way to learn more about the language/framework, as well as adding some new functionality. 

## Prerequisites

- .NET SDK 10 or later

## Build and test

```bash
dotnet build
dotnet test
```
